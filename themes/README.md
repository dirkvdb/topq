# Bundled themes

These JSON theme sets are adapted from [GPUI Kit's themes](https://github.com/longbridge/gpui-kit/tree/main/themes), distributed under Apache-2.0.

- Ayu: Zed Industries. Muted text and light primary-button text contrast increased using colors from the same palette; unused editor diagnostic styles omitted.
- Tokyo Night: Folke Lemaitre, <https://github.com/folke/tokyonight.nvim>. Night variant retained; Storm and Moon omitted.
- `collection.json` adapts themes from `../tabulite/themes`. All UI colors are retained, with editor highlighting limited to JSON payload syntax and editor surfaces:
  - Catppuccin: Catppuccino, <https://github.com/catppuccin/catppuccin> (Latte, Frappe, Macchiato, Mocha).
  - Gruvbox: Pavel Pertsev, <https://github.com/morhetz/gruvbox> (Light, Dark).
  - Solarized: Ethan Schoonover, <https://ethanschoonover.com/solarized> (Light, Dark).
  - Everforest: sainnhe, <https://github.com/sainnhe/everforest> (Light, Dark).
  - Matrix: iruzo, <https://github.com/iruzo/matrix-nvim>.

The application embeds these files, so themes work independently of the working directory.
